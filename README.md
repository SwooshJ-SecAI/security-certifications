## Description

A centralized knowledge base for security certification preparation and compliance framework study. Each directory contains domain-specific notes, practice questions, key takeaways, and reference materials organized for efficient review and long-term retention.

## Repository Structure

```
security-certifications/
|-- comptia/              # CompTIA Security+, CySA+, CASP+ materials
|-- soc2/                 # SOC 2 Type I/II audit preparation
|-- iso27001/             # ISO 27001 ISMS framework and controls
|-- hipaa/                # HIPAA security and privacy rule study
|-- notes-template.md     # Standardized template for all study notes
|-- .gitignore
|-- README.md
```

## Features

- Standardized note-taking template for consistency across all certifications
- Domain-specific directories with structured study materials
- Practice question sets organized by exam objective
- Compliance framework mappings and control references
- Progress tracking per certification domain

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/SwooshJ-SecAI/security-certifications.git
   ```
2. Copy `notes-template.md` into the relevant certification directory
3. Rename the copy to match the topic or exam domain
4. Fill in study notes following the template structure

## How to Use

Each certification directory follows the same pattern:

- `notes/` -- Detailed study notes organized by domain
- `practice/` -- Practice questions and scenario walkthroughs
- `resources.md` -- Curated list of study materials and references
- `progress.md` -- Personal tracking of completed objectives

Use the `notes-template.md` at the root as the starting point for any new topic.
